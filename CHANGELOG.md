# Changelog

## 0.1.0-alpha.1 — 2026-10-28

- First public-test candidate for Windows x64.
- Actual short-window/weekly quota queried through the installed Codex App Server.
- Compact yellow remaining-quota bars and blue daily-use segment.
- Codex-only foreground display, tray controls and saved position.
- Fixed daily planning budget, account-separated ledgers and same-day reset segments.
- Local application data storage, single-instance guards and failure backoff.
- Portable runtime build, bilingual documentation, privacy statement and automated checks.

Test status is documented in `docs/TESTING.md`. This is an alpha; it has not been validated by an external user panel or across all Codex plans.
